FaithConnection functional fix
===============================

Configuration was intentionally preserved:
- Firebase configuration values were not changed.
- API_BASE_URL remains https://faithconnection.free.je/api.php.
- Existing database connection values in api.php/config.php were not changed in the source configuration.
- Existing theme variables/design were preserved; style.css only adds helper rules for newly activated UI.

Main fixes:
- Profile navigation + profile rendering/editing.
- Followers/following + follow/unfollow.
- Post create/edit/delete/share/like/pray/save/comments.
- Ministries/groups create/join/leave/admin-add-member.
- WhatsApp-style group chat + photo messages.
- Direct 1-to-1 chat + photo messages + quick prayer + polling.
- Active believers search + profile/message/follow.
- Settings navigation + theme persistence.
- Stories and daily verse interactions.
- Global search.
- Backend API now creates/migrates the missing social tables on the existing MySQL database.

Deployment:
1. Replace the live app.js, api.php and style.css with these versions.
2. Do not replace config.php unless you intentionally want to change credentials.
3. Keep index.html and the remaining project files as they are.
4. If your database user cannot CREATE/ALTER tables, run the database setup with an account that has those permissions first.
