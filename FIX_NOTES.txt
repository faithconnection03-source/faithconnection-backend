FaithConnection v2 authentication fix
=====================================

ROOT CAUSE FOUND:
The previous functional build sent email/registration requests to
https://faithconnection.free.je/api.php. That hostname is currently not resolving,
which produces the browser error "Failed to fetch" on Netlify.

FIX:
- Email/password registration now uses the existing Firebase Authentication config.
- Email/password login now uses Firebase Authentication.
- Username/mobile login resolves the user's email from the existing Firestore users collection.
- New registration stores the complete profile (name, username, email, phone, role, church, bio, avatar) in Firestore.
- Firebase profile loading is used before the optional MySQL API.
- App boot no longer depends on the PHP API being online.
- Existing Firebase configuration is unchanged.
- Existing theme/design and index.html are unchanged.
- The MySQL API remains available for the social/community data layer when its backend is online.

IMPORTANT:
Firebase Email/Password Authentication must be enabled in Firebase Console > Authentication > Sign-in method.
The password must be at least 6 characters because Firebase Authentication enforces that minimum.
