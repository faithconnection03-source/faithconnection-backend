# FaithConnection — Modern Social Media & Fellowship Web Platform

A complete, responsive, and feature-rich social media web application built with clean, modern HTML5, CSS3, and JavaScript (ES6+).

---

## 🌟 Features Included

- **🔐 Authentication & Roles**:
  - Sign in, Create Account, and 1-Click Guest/Google demo login.
  - Ministry role selection (*Worship Leader, Youth Leader, Pastor, Prayer Warrior, etc.*) and church affiliation.
- **📱 Feed & Stories**:
  - Status/Stories ring bar with auto-advancing story viewer.
  - Rich Post Creator with real-time image file upload & preview (`FileReader`).
  - Like / Amen heart counters, "🙏 I Prayed for This" commitment button.
  - Full comment threads with inline editing and deletion.
  - Post bookmarking & Web Share API support.
- **📖 Daily Bread & Scriptures**:
  - Daily verse inspiration hero card with Next Verse, Share, and Copy buttons.
  - Curated scripture cards by category (Peace, Strength, Healing, Provision).
- **👥 Active Believers Directory**:
  - Live search/filtering of online believers by name, ministry role, or church.
  - Connect / Friend buttons with reciprocal state.
- **⛪ Ministries & Fellowships**:
  - Browse and join/leave specialized ministry groups.
  - Create new custom ministry groups with modal.
- **💬 Direct Messaging & Real-Time Chat**:
  - Full fellowship chat interface with message bubbles and photo sharing.
  - Interactive bot simulating responses from fellow believers.
  - Direct "Send Amen Prayer" button.
- **👤 User Profile & Customization**:
  - Profile header with cover banner, role pill, bio, and church name.
  - Real-time stat counters (Posts, Friends, Ministries).
  - Sub-tabs: *My Posts*, *Friends List*, *Saved Posts*.
  - Full profile editing modal with custom avatar upload.
- **🎨 Modern Design & Theming**:
  - Dark Space Theme and Clean Light Mode with persistent LocalStorage settings.
  - Glassmorphic card styling, floating toast notifications, and mobile bottom navigation bar (< 768px).

---

## 🚀 How to Run

1. Open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).
2. Click **"1-Click Continue as Guest / Google"** for instant demo access, or create a custom account!
